# FraudGuard - Learning Notes

## 1. Git
Git is a version control system that tracks changes in project files.

## 2. Git Repository
A repository stores project files and their version history.

## 3. Git Commit
A commit is a saved snapshot of tracked project changes.

## 4. Docker
Docker packages applications and their dependencies into containers.

## 5. Docker Engine
The Docker Engine creates and manages containers.

## 6. Docker Compose
Docker Compose manages multiple containers using a configuration file.

## 7. Python Virtual Environment
A virtual environment isolates Python dependencies for a project.

## Learning Rule
For every new concept, document:
- Definition
- Purpose in FraudGuard
- How it works
- Practical implementation
- Testing
- Revision questions
