# FraudGuard

FraudGuard is a modular fraud detection and suspicious-message analysis system.

## Project Goals
- Detect suspicious financial transactions.
- Analyse suspicious messages.
- Compare traditional machine learning and transformer models.
- Provide risk assessments and explanations.
- Build backend APIs, an analyst dashboard and an Android application.

## Technology Stack
- Python
- Scikit-learn
- XGBoost
- PyTorch and Transformers
- FastAPI
- PostgreSQL
- Docker and Docker Compose
- React
- Kotlin and Jetpack Compose

## Development Approach
Learn -> Understand -> Implement -> Test -> Document -> Revise
